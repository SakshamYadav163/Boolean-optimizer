# Boolean-optimizer
De Morgan's Theorem Logic Gate Optimizer
A comprehensive Python tool for simplifying digital logic circuits using De Morgan's theorem and boolean algebra optimization techniques. This tool provides interactive circuit analysis, optimization visualization, and truth table generation.

Features
🔧 Logic Circuit Optimization: Automatically applies De Morgan's theorem and boolean algebra simplifications
📊 Truth Table Generation: Creates complete truth tables for original and optimized circuits
📈 Optimization Metrics: Shows gate count reduction and percentage savings
🎯 Interactive Mode: User-friendly interface for circuit analysis
📋 Predefined Circuits: Includes common digital logic circuits (NAND, NOR, Adders, etc.)
🔍 Step-by-step Analysis: Optional display of optimization steps
📱 Circuit Visualization: Visual representation of logic circuits
💻 Command Line Interface: Supports batch processing and automation
