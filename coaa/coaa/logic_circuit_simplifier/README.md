# Logic Circuit Simplifier

A Python application that simplifies logic circuits using De Morgan's theorem and other Boolean algebra rules.

## Features

- **Boolean Expression Parsing**: Parse complex Boolean expressions with support for AND, OR, NOT, XOR, NAND, NOR operators
- **Circuit Simplification**: Apply De Morgan's laws, absorption laws, complement laws, and other Boolean algebra rules
- **Visual Circuit Representation**: Generate circuit diagrams using Graphviz
- **Truth Table Verification**: Verify that simplified circuits are logically equivalent to originals
- **Interactive Web Interface**: User-friendly Streamlit interface
- **Comprehensive Testing**: Unit tests for all simplification rules
